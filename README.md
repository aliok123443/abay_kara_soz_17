# Он жетінші қара сөз — Абай Құнанбаев

Бұл репозиторий GitHub Pages-ке арналған дайын бір файлдық веб-сайт (презентация).

## GitHub Pages-ке қалай жүктеу керек:

1. Осы папкадағы `index.html` файлын GitHub-тағы репозиторийіңіздің негізгі тармағына (`main` немесе `master`) салыңыз (upload немесе `git push`).
2. GitHub репозиторийіңіздің **Settings** -> **Pages** бөліміне өтіңіз.
3. **Build and deployment** бөлімінен:
   - Source: **Deploy from a branch**
   - Branch: **main** (немесе `master`), папка: **/ (root)**
   - **Save** батырмасын басыңыз.
4. 1-2 минуттан кейін сайтыңыздың сілтемесі дайын болады!

## Мүмкіндіктері:
- 📱 **Телефондарға арналған ыңғайлы өлшем**:
  - Төменгі оң жақта — «Келесі» батырмасы.
  - Төменгі сол жақта — «Алдыңғы» батырмасы.
  - Ортасында — бет санауышы және толық экранға / бұруға арналған батырма.
  - Сенсорлық экранда саусақпен оңға/солға сырғыту (swipe).
- 💻 **Компьютерге арналған нұсқа**:
  - Пернетақтадағы бағыттауыштармен (← және →) немесе бос орын (Space) арқылы ауыстыру.
  - Үстіңгі нүктелерді басу арқылы кез келген слайдқа өту.
